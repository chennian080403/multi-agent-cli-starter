# 多 Agent 协作小白 60% 够用包：1 主 + 1 从 CLI，10 分钟告别复制粘贴

> **核心理念**：别再一边用 ChatGPT / Codex 写方案，一边全文复制粘贴到 WorkBuddy 干活了——你不是老板，你是两个 AI 之间的传话筒。
>
> **人只做三件事**：说清需求、扫码/登录授权、看结果拍板。装环境、接 CLI、写规矩，全部交给你的主 AI 自己干。

---

## 这个包里有什么（一共就 3 个文件，拿来即用）

| 文件 | 给谁看 | 干什么用 |
|---|---|---|
| `README.md`（本文件） | **给人看**（3 分钟） | 搞懂思路、确认你的主/从搭配、知道下一步点哪里 |
| `01-发给主AI的接入说明书.md` | **发给你的主 AI** | 让主 AI 自动检测环境、装好从属 CLI、引导你授权、跑通一次调用测试 |
| `02-派活与交接极简规矩.md` | **发给主 AI 存进规则** | 3 条铁律 + 共享 `PROGRESS.md` 模板，彻底告别上下文割裂和重复粘贴 |

---

## 3 分钟傻瓜上手（只有 3 步）

### 第 1 步：选定你的「1 主 + 1 从」组合

不需要贪多，先挑你手里已经在用的两个工具：
- **常见组合 A**：主用 **Codex**（桌面端或终端） + 从用 **WorkBuddy / CodeBuddy CLI**
- **常见组合 B**：主用 **WorkBuddy** + 从用 **Codex CLI**
- **常见组合 C**：主用 **Claude Code（CC）** + 从用 **Codex CLI**（或 Kimi Code CLI / Pi CLI）
- **常见组合 D**：哪怕你现在还没配好 CLI，也先用包里的 `PROGRESS.md` 共享进度法，立刻省掉 80% 复制粘贴

### 第 2 步：把说明书直接丢给你的主 AI

打开你平常用的**主 AI**，把本目录里的 `01-发给主AI的接入说明书.md` 拖进对话框（或复制全文发给它），然后只补一句话：

> 「按这份说明书帮我配置多 Agent CLI 协作。我准备主用【填你的主 AI】，让【填你想接的从 CLI】给我打杂执行，一步步引导我完成。」

主 AI 会自动帮你检查电脑环境、安装对应官方 CLI、在需要登录时提示你点哪里授权，并跑通一次最小验证。

### 第 3 步：把 3 条极简规矩写进长期记忆

验证跑通后，再把 `02-派活与交接极简规矩.md` 发给主 AI，对它说一句：

> 「把这份派活和交接规矩写进我的全局规则文件（`AGENTS.md` 或 `CLAUDE.md`），以后干活都照这个来。」

到这里，你就已经拿到多 Agent 协作最爽的 **60% 效果**了。

## 进阶成长地图（先拿稳 60%，再决定要不要升级）

| 阶段 | 形态 | 你能拿到什么 |
|---|---|---|
| **阶段一（本包，60% 够用）** | 桌面主 Agent + 1 个从 CLI + `PROGRESS.md` | 彻底告别手动复制粘贴，10 分钟上手 |
| **阶段二（80% 进阶）** | 终端双 CLI 明确分工（如 Claude Code + Codex CLI） | 主脑只管规划和验收，杂活外包，省一半额度和上下文 |
| **阶段三（100% 满血）** | 四家 CLI 双向打通（CC + Codex + Pi + Kimi Code）+ 无缝交接 | 便宜模型 1 分钟筛完几千条素材，高难工程换强模型交叉复核，不怕单家限流 |

> **避坑提醒**：半小时内单会话能干完的小活，直接用一个 AI 一把梭更快，不要为了显得高级硬拆给好几个 Agent。
